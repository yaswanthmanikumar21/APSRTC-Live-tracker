        About

        APSRTC Live is a free, crowdsourced Visakhapatnam bus tracker using rider-submitted GPS data. It is a community project, not officially affiliated with APSRTC.

        How it works

        Search for your bus to see its live location when someone shares it. If you are riding, tap “I'm on this bus” to help other riders.

        Privacy

        Location is collected only when a user taps “I'm on this bus”, shared temporarily, expires automatically, and is not linked to personal identity. It is used only to show bus positions.

        Disclaimer

        This crowdsourced community tool depends on user participation; location may not always be available or accurate.

        Contact
